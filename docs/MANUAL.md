# 大肥鱼 · B站浏览插件 功能与配置手册

适用版本 **v0.8.2**（2026-10-25 上线）。本文件写给主人看：它能做什么、边界在哪、每个数字在哪里改。

- 插件目录（云端）：`/opt/qqbot/astrbot/data/plugins/astrbot_plugin_feiyu_bili`
- 配置（云端）：`/opt/qqbot/astrbot/data/config/astrbot_plugin_feiyu_bili_config.json`（UTF-8 **带 BOM**）
- 数据库（云端）：`/opt/qqbot/astrbot/data/plugin_data/astrbot_plugin_feiyu_bili/browse.db`（`user_version=7`）
- 开源：https://github.com/Deepsleep-one/astrbot-plugin-feiyu-bili

---

## 1. 它到底做了什么

一句话：**你让她读，她就真的读（字幕 + 画面）；她自己逛，就逛得克制（每天十轮、最多分享五条）；读到的认识要你点头才算数。**

| 能力 | 你会看到 | 边界 |
|---|---|---|
| 指定阅读 | `/刷站 读 BV号` → 分页正文、时间戳、来源（官方字幕 / 机器转写 / 只有元数据） | 只读公开视频；不下载到长期存储 |
| 深读看画面 | `/刷站 深读 BV号` → 真实抽帧送多模态模型，正文里多出"画面看到了什么" | 默认 12 帧/次（硬上限 40）；单帧 2MB、单条视频流 32MB |
| 八栏手账 | `/刷站 手账` → 遇见、材料事实、作者观点、我的推测、先前判断、认识修正、遗漏、下次如何回应 | 草稿状态 `pending_review`，**不自动写** |
| 认识（可纠错） | `/刷站 收下` 才建"认识"；`认识` / `更正 <id>` / `忘掉 <id>` 全程可追溯 | 只以"派生整理"入库，永不冒充你的事实 |
| 自主浏览 | 她自己按 30–240 分钟间隔逛，一天 10 轮，落在 09:00–21:36 | 夜间 23:00–09:00 不排轮次 |
| 点赞 | 字幕证据足够 + 她判断喜欢 → 点赞（每日 3） | 无字幕不点赞；结果不明也占额；只增不减 |
| 分享 | 挑一条值得的视频发你，一天最多 5 条、按全天摊开 | 23–9 点不发；两条间隔 ≥120 分钟 |
| 评论区（只读） | `/刷站 评论 [BV号]` → 第一页 + 置顶 + UP 主楼中楼答复 | 只在你要求时读；不回复、不点赞评论、不建档案 |
| 弹幕（只读） | `/刷站 弹幕 [BV号]` → 按时间分桶的抽样，带 ×N 热度 | 只读这一 P 的静态 XML；不发弹幕、不滚屏 |
| 机器转写 | `/刷站 转写 [BV号]` → 这一 P 没字幕时，本机小模型把音频转文字 | 每天 5 次、单条 <30 分钟、跑在本机、用完删音频 |
| 想读清单 | `/刷站 提议` → 她列出想读的候选；`读 1` 才真读 | 她只能提议，**不自动读、不自动花钱** |

## 4. 数值怎么改

### 4.1 先记住这个乘法

> **每天最多读几条 = `videos_per_round` × `daily_rounds`**

默认 `3 × 10 = 30` 条/天（硬上限 `5 × 16 = 80`）。"读"指读字幕并做判断，不等于分享；分享另有 5 条额度。

### 4.2 浏览与节律

| 键 | 默认 | 硬上限 | 改大了会怎样 |
|---|---|---|---|
| `enabled` | true | — | 总开关，关掉连 `/刷站 刷` 也停 |
| `daily_rounds` | **10** | 16 | 一天逛更多轮；间隔按"剩余轮次 ÷ 剩余可说话时间"自动缩短（最短 30 分钟） |
| `videos_per_round` | **3** | 5 | 每轮多读候选，单轮耗时与模型调用同比例上升 |
| `daily_shares` | **5** | 5 | 每天最多分享几条（仍受 09→1、12→2、15→3、18→4、21→5 的阶梯限制） |
| `share_cooldown_minutes` | 120 | 最少 30 | 两条分享最短间隔；调小会和阶梯叠加，出现堆积 |
| `daily_likes` | 3 | 10 | 每天最多点赞；结果不明也占额 |
| `auto_like` | false（**线上已开 true**） | — | 关掉后只浏览不点赞 |
| `quiet_start` / `quiet_end` | 23 / 9 | 取值 0–23 | QQ 静默窗口；**也是分享额度阶梯的起点**（窗口越窄，一天能解锁的额度越少） |
| `topics` | 4 个种子 | — | 公开兴趣种子，不是播放列表，她会沿推荐自行拓展 |

### 4.3 画面上限（深读与后台看图）

| 键 | 默认 | 硬上限 | 说明 |
|---|---|---|---|
| `vision_enabled` | true | — | 关掉后深读只读字幕，并诚实说"画面不可用" |
| `deep_read_frames` | 12 | 40 | 你要求深读时一 P 最多抽几帧 |
| `auto_vision` | **true** | — | 后台每轮最多对 1 条真抽帧（画面不能反过来买点赞/分享） |
| `auto_vision_shadow` | true | — | 只记录"本来会看哪一条、为什么跳过"，不下载不调模型 |
| `auto_vision_frames` | 4 | 4 | 后台那一条抽几帧 |
| `media_max_mb` | 32 | 64 | 单条受限视频流下载上限 |
| `frame_max_kb` | 2048 | 2048 | 单帧 JPEG 上限 |
| `media_timeout_s` | 180 | 600 | 单次抽帧任务总超时 |
| `frame_keep_hours` | 72 | — | 帧文件保留小时数，过期自动删（只留文字证据） |
| `vision_provider_id` | `xiaomi/mimo-v2.6-flash` | — | 专门看图的模型；留空则用聊天模型 |

### 4.4 认识与记忆

| 键 | 默认 | 说明 |
|---|---|---|
| `growth_memory_sync` | true | 收下手账后，把认识以「派生整理」写进 `feiyu_memory`（不是你的事实）；关掉就只留本插件 |
| `proposal_limit` | 3 | 一次最多列几条想读候选（≤5）；读不读由你决定 |

### 4.5 只读采集与转写

| 键 | 默认 | 硬上限 | 说明 |
|---|---|---|---|
| `comments_enabled` / `comments_limit` | true / 8 | 20 | 评论区第一页条数；只在你要时读 |
| `danmaku_enabled` / `danmaku_limit` | true / 40 | 120 | 弹幕抽样条数（按时间分桶，不是全量） |
| `asr_enabled` | true | — | 允许"没字幕时本机转写" |
| `asr_background` | **false** | — | 后台轮次**不**启动转写（省额度、省电） |
| `asr_model` / `asr_compute_type` | small / int8 | — | 必须写死；不会静默换模型或下载更大权重 |
| `asr_threads` | 2 | 8 | CPU 线程；调高会挤占你正在用的程序 |
| `asr_daily_limit` | 5 | 5 | 每天转写次数（失败/超时也计次） |
| `asr_max_seconds` | 1799 | — | 单条 <30 分钟；超限整条跳过，不截前段冒充 |
| `asr_total_timeout_s` | 1200 | 1800 | 整个转写任务总 deadline |
| `asr_endpoint` / `asr_endpoint_token` | 云端已有 | — | 权威执行端地址与口令（本机 small） |

### 4.6 三套预设（直接抄）

| | 安静省钱 | 标准（当前） | 活跃 |
|---|---|---|---|
| `daily_rounds` | 4 | **10** | 14 |
| `videos_per_round` | 2 | **3** | 4 |
| `daily_shares` | 2 | **5** | 5 |
| `daily_likes` | 1 | **3** | 5 |
| `auto_vision` | false | **true** | true |
| 每天最多读 | 8 条 | **30 条** | 56 条 |

### 4.7 改的两个入口

1. **AstrBot WebUI**（推荐）：插件管理 → 大肥鱼B站浏览 → 配置，改完保存。多数键**保存即生效**（插件每轮读取 `self.config`）。
2. **直接改文件**（云端）：`/AstrBot/data/config/astrbot_plugin_feiyu_bili_config.json`，**必须保持 UTF-8 BOM**（用 `utf-8-sig` 读写），改完 `docker restart astrbot`。

改完用 `/刷站 状态` 核对：它会把当前轮次上限、点赞占额、分享额度、最近一次失败原因都打出来。

## 5. 明确不会发生的事

- 不读、不展示 token / Cookie / 私钥 / 真实私聊；签名媒体 URL 不落库、不给模型。
- 不新建第二条 QQ 通道、不新增收藏/投币/评论/私信/上传；评论只读不回复。
- 不发弹幕、不点赞弹幕、不滚屏抓弹幕。
- 不自动语音（只在你要她说时才出声）。
- 不自动读她提议的候选；不自动写手账。
- 不让画面证据反过来放宽点赞/分享；机器转写也不放宽分享、不提高点赞额度。
- 不调云 ASR、不外发音频（跨机时音轨只在本机，云端只发 bvid/cid）。
- 夜间 23:00–09:00 不发消息，但还会浏览（浏览不打扰你）。

## 6. 常见问题

**Q：为什么她今天什么都没发？**
看 `/刷站 状态` 末行：①`auto` 是否开着；②轮次是否用完；③分享额度是否还没解锁（早上只有 1 条）；④最近一次失败原因（如 `TypeError`）；⑤是不是夜间静默。五个原因之外，还有"没读到值得分享的"。

**Q：为什么深读说"画面不可用"？**
三种情况：`vision_enabled` 关了、解码器不在（`ffmpeg` 缺失）、这一 P 有版权/登录限制取不到流。插件会如实报具体原因，不会假装看过。

**Q：为什么点赞明明点了、她又说没点过？**
B站回读有最终一致延迟（POST 成功后立刻读可能还是 0），隔几秒或换进程读即为 true。判断成败看 POST 返回码，不用慌。

**Q：手账为什么一直是 0 篇？**
后台不自动写（你 2026-10-25 的选择）。要么 `/刷站 手账`，要么对话里她自己调 `feiyu_keep_journal`。

**Q：想让她只逛不分享？**
`daily_shares=0`。

**Q：想让她只在你叫她才动？**
`/刷站 关闭`（或 `auto=false`），此后 `/刷站 读`、`深读`、`刷` 依然可用。

## 7. 回滚与备份

- 备份目录：`/opt/qqbot/feiyu-bili-backups/`（每次上线前自动留一份，权限 700）。

- 降级到 v0.8.1 后 `daily_shares=5` 会被旧硬上限夹到 3；`user_version` 仍是 7，不需要迁移。
